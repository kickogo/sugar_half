## goods 商品集合

### 字段结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `_id` | string | ✅ | 云数据库自动生成，主键 |
| `name` | string | ✅ | 商品名称 |
| `price` | number | ✅ | 基础价格（元） |
| `imageUrl` | string | ✅ | 商品图片（云存储 fileID） |
| `status` | number | ✅ | 1=上架 0=下架 |
| `isRecommend` | boolean | ✅ | 是否推荐到首页 |
| `buyCount` | number | ✅ | 累计销售数量 |
| `category` | string | ✅ | 分类ID（如"birthday"） |
| `desc` | string | ❌ | 商品描述（替代原 `tag`） |
| `specConfig` | object | ✅ | 规格选项配置（见下方） |
| `createdAt` | number | ❌ | 创建时间（时间戳） |
| `updatedAt` | number | ❌ | 更新时间 |

### specConfig 子对象

```js
specConfig: {
  size: [           // 份量，必选
    { name: "6寸 2-3人份", price: 0 },
    { name: "8寸 4-6人份", price: 40 },
    { name: "10寸 8-10人份", price: 80 }
  ],
  filling: ["桑椹莓莓", "芋泥啵啵", "布丁燕麦脆"],  // 夹心，单选
  card: ["需要", "不需要"],      // 插牌/生日帽，单选
  candle: ["数字蜡烛", "长条蜡烛", "无需蜡烛"],  // 蜡烛，单选
  mention: ["需要", "不需要"],   // 贺卡，单选
  packaging: [        // 包装，必选
    { name: "礼盒", price: 0 },
    { name: "保冷包", price: 5 }
  ],
  cream: [           // 奶油加量，必选
    { name: "无需增量", price: 0 },
    { name: "加奶油1份", price: 8 }
  ]
}
```

## cart 购物车集合

### 字段结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `_id` | string | ✅ | 云数据库自动生成，主键 |
| `_openid` | string | ✅ | 用户 openid |
| `goodsId` | string | ✅ | 关联商品 `_id` |
| `spec` | object | ✅ | 已选规格（见下方 CartSpec） |
| `quantity` | number | ✅ | 购买数量 |
| `createdAt` | number | ❌ | 创建时间 |
| `updatedAt` | number | ❌ | 更新时间 |

### CartSpec 对象（spec 字段）

```js
spec: {
  size: "8寸 4-6人份",     // 份量
  filling: "桑椹莓莓",      // 夹心
  card: "不需要",           // 插牌/生日帽
  candle: "数字蜡烛",       // 蜡烛
  mention: "不需要",        // 贺卡
  packaging: "礼盒",        // 包装
  cream: "无需增量"         // 奶油加量
}
```

> ⚠️ `spec` 不再是字符串格式 `"6寸 2-3人份 · 桑椹莓莓 · ..."`，而是对象格式。

## orders 订单集合

### 字段结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `_id` | string | ✅ | 云数据库自动生成，主键 |
| `_openid` | string | ✅ | 用户 openid |
| `items` | array | ✅ | 订单商品列表（见下方） |
| `totalPrice` | number | ✅ | 订单总价（元） |
| `address` | object | ✅ | 收货地址信息 |
| `phone` | string | ✅ | 联系电话 |
| `remark` | string | ❌ | 订单备注 |
| `status` | string | ✅ | 订单状态 |
| `createdAt` | number | ❌ | 创建时间 |
| `paidAt` | number | ❌ | 支付时间 |
| `updatedAt` | number | ❌ | 更新时间 |

### OrderItem 对象（items 数组元素）

```js
items: [{
  goodsId: "goods_001",      // 商品ID
  name: "芭乐布蕾",          // 商品名称（冗余）
  spec: "8寸 4-6人份 · ...",  // 规格描述字符串（兼容旧数据）
  unitPrice: 338,             // 下单时的单价
  quantity: 1,                // 购买数量
  imageUrl: "cloud://..."     // 商品图片（冗余）
}]
```

### Address 对象

```js
address: {
  name: "张三",            // 收货人姓名
  phone: "13800138000",    // 联系电话
  province: "广东省",      // 省
  city: "深圳市",          // 市
  district: "龙华区",      // 区
  detail: "花样城购物中心1楼"  // 详细地址
}
```

### status 订单状态流转

```
PENDING_PAY → PAID → BAKING → SHIPPING → FINISHED
                ↓
            CANCELLED（中途取消）
```

## scores_log 积分变动日志集合

### 字段结构

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `_id` | string | ✅ | 云数据库自动生成，主键 |
| `_openid` | string | ✅ | 用户 openid |

| `currentScores` | number | ✅ | 变动后当前积分余额 |
| `createdAt` | number | ❌ | 创建时间 |

## 接口文件索引

### .interface.ts — 开发参考（IDE 智能提示）

| 文件 | 用途 |
|------|------|
| `database.interface.ts` | 统一导出所有接口 |
| `spec.interface.ts` | 规格配置结构定义 |
| `goods.interface.ts` | 商品表接口 |
| `cart.interface.ts` | 购物车表接口 |
| `user.interface.ts` | 用户表接口 |
| `order.interface.ts` | 订单表接口 |
| `scoresStore.interface.ts` | 积分商城接口 |
| `scoresLog.interface.ts` | 积分日志接口 |

### .schema.json — 云数据库导入（云控制台直接导入）

| 文件 | 集合名 | 用途 |
|------|--------|------|
| `goods.schema.json` | `goods` | 商品表结构 |
| `goods_data.json` | `goods` | 商品初始化数据（可直接导入） |
| `cart.schema.json` | `cart` | 购物车表结构 |
| `cart_data.json` | `cart` | 购物车初始数据（空） |
| `users.schema.json` | `users` | 用户表结构 |
| `users_data.json` | `users` | 用户初始数据（可直接导入） |
| `orders.schema.json` | `orders` | 订单表结构 |
| `orders_data.json` | `orders` | 订单初始数据（空） |
| `scores_store.schema.json` | `scores_store` | 积分商品表结构 |
| `scores_store_data.json` | `scores_store` | 积分商品初始化数据（可直接导入） |
| `scores_log.schema.json` | `scores_log` | 积分日志表结构 |
| `scores_log_data.json` | `scores_log` | 积分日志初始数据（空） |

**导入方式：** 微信开发者工具 → 云开发控制台 → 数据库 → 选中对应集合 → 导入 `*_data.json` 文件
