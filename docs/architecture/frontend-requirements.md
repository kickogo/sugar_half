# 前端需求分析文档

## 1. 前端技术栈说明

### 1.1 核心技术选型

| 技术 | 说明 | 选择原因 |
|------|------|----------|
| **Skyline 渲染器** | 微信小程序新一代渲染引擎 | 相比 WebView 有更好的渲染性能，支持更灵活的组件化开发 |
| **glass-easel** | 组件框架 | 轻量级、高性能，支持组件式开发，适合 Skyline 架构 |
| **微信小程序原生 API** | wx.cloud、wx.request 等 | 与云开发深度集成，原生支持微信支付、登录等能力 |

### 1.2 技术特点

- **模式**: 仅支持 `Skyline` 模式（不使用 `webkit` 模式）
- **组件化**: 全程组件化开发，页面也是组件
- **类型**: 默认 ES Module
- **兼容**: 需支持 iOS 12+ 和 Android 主流版本

## 2. 页面清单及核心功能

### 2.1 页面总览

| 页面路径 | 文件夹 | 核心功能 | 优先级 |
|---------|--------|----------|--------|
| 首页 | `pages/index/` | Banner展示、分类入口、推荐商品 | P0 |
| 分类页 | `pages/category/` | 商品分类浏览 | P0 |
| 商品详情页 | `pages/product/` | 商品信息、SKU选择、加入订单 | P0 |
| 订单确认页 | `pages/order/` | 地址选择、预约时间、配送方式、订单摘要 | P0 |
| 预约页面 | `pages/reservation/` | 日期选择、时间段选择（复用组件） | P0 |
| 支付页 | `pages/payment/` | 微信支付 | P0 |
| 个人中心 | `pages/my/` | 用户信息入口 | P1 |
| 订单列表 | `pages/my/orderList/` | 订单历史 | P1 |
| 订单详情 | `pages/my/orderDetail/` | 订单完整信息 | P1 |
| 地址管理 | `pages/my/address/` | 地址CRUD | P1 |
| 会员中心 | `pages/my/member/` | 余额、积分展示 | P2 |

### 2.2 首页 (index)

**核心功能**:
- 店铺 Banner 轮播（自动播放 + 指示器）
- 分类快捷入口（图标 + 名称）
- 推荐商品列表（图片 + 名称 + 价格）
- 底部导航栏

**页面状态**:
- 加载中：骨架屏或 Loading 动画
- 加载失败：重试按钮
- 空数据：友好的空状态提示

### 2.3 分类页 (category)

**核心功能**:
- 左侧分类列表（吸顶效果）
- 右侧商品列表（按分类筛选）
- 商品点击跳转详情页

**页面状态**:
- 默认显示第一个分类的商品
- 下拉刷新
- 上拉加载更多（分页）

### 2.4 商品详情页 (product)

**核心功能**:
- 商品图片轮播（支持预览）
- 商品名称、描述、价格展示
- **SKU 选择器**（规格联动价格）
- 预约日期选择
- 预约时间段选择
- 加入订单按钮

**页面状态**:
- 未选择规格：规格选择区提示"请选择规格"
- 规格选择中：联动更新价格
- 库存不足：规格项置灰，显示"缺货"

### 2.5 订单确认页 (order)

**核心功能**:
- 商品摘要（可修改数量）
- 配送方式选择（自提/配送）
- 收货地址选择（配送时必填）
- 预约日期/时间段展示
- 订单备注输入
- 价格明细（商品金额、优惠、配送费）
- 提交订单

**页面状态**:
- 配送方式切换影响地址显示
- 地址为空时引导新增

### 2.6 预约页面 (reservation)

**核心功能**:
- 日历组件（日期选择）
- 时间段选择（展示可用/已满状态）
- 确认预约

**组件复用**: 此页面的日期选择器和时间段选择器应设计为可复用组件

### 2.7 支付页 (payment)

**核心功能**:
- 订单摘要展示
- 应付金额展示
- 微信支付按钮
- 支付状态轮询

**页面状态**:
- 支付中：禁止重复点击
- 支付成功：跳转成功页
- 支付失败：显示错误原因，可重试

### 2.8 个人中心 (my)

**核心功能**:
- 用户信息展示（头像、昵称、会员等级）
- 功能入口（我的订单、收货地址、会员中心）
- 快捷操作（联系客服）

### 2.9 订单列表 (my/orderList)

**核心功能**:
- 订单筛选（全部/待付款/制作中/已完成）
- 订单卡片展示（商品图片、订单状态、金额）
- 分页加载

### 2.10 订单详情 (my/orderDetail)

**核心功能**:
- 订单完整信息（商品、物流、预约时间等）
- 订单状态跟踪
- 底部操作按钮（付款/取消/联系客服）

## 3. 模块划分与职责

### 3.1 模块架构

```
┌─────────────────────────────────────────────┐
│                   UI 层                      │
│  (页面组件 + 业务组件)                        │
├─────────────────────────────────────────────┤
│                 逻辑层                       │
│  (业务逻辑、数据处理)                         │
├─────────────────────────────────────────────┤
│                服务层                        │
│  (API 调用、鉴权、支付封装)                   │
└─────────────────────────────────────────────┘
```

### 3.2 模块职责

| 模块 | 位置 | 职责 |
|------|------|------|
| **用户模块** | `services/auth.js` + `pages/my/` | 登录态管理、用户信息获取 |
| **商品模块** | `services/api.js` + `pages/category/` + `pages/product/` | 商品查询、SKU 联动 |
| **订单模块** | `services/api.js` + `pages/order/` + `pages/payment/` | 订单创建、支付流程 |
| **预约模块** | `components/reservation/` + `pages/reservation/` | 日期时间选择 |
| **地址模块** | `services/api.js` + `pages/my/address/` | 地址 CRUD |
| **通用模块** | `components/` | 导航栏、按钮、单元格等 |

| 组件 | 路径 | 用途 |

## 4. 用户交互流程

### 4.1 主流程：商品浏览到支付

```
[首页] → [分类页/商品详情] → [SKU选择] → [订单确认页]
                                                      ↓
                                              [选择配送地址/时间]
                                                      ↓
                                                  [提交订单]
                                                      ↓
                                                 [支付页面]
                                                      ↓
                                              [微信支付] → [支付成功]
```

### 4.2 用户登录流程

```
[打开小程序] → [检查本地登录态]
                        ↓
              ┌─────────┴─────────┐
              ↓                   ↓
          有登录态              无登录态
              ↓                   ↓
        获取用户信息          [微信授权]
              ↓                   ↓
        检查手机号            [获取手机号]
              ↓                   ↓
          已绑定                  未绑定
              ↓                   ↓
        返回首页              引导绑定手机
```

### 4.3 SKU 选择交互

```
[进入商品详情页]
       ↓
[点击规格分类（如"尺寸"）]
       ↓
[展开规格选项列表]
       ↓
[选择规格值（如"8寸"）]
       ↓
[联动更新其他规格的可用性]
       ↓
[联动计算SKU价格和库存]
       ↓
[显示选中规格组合的价格]
```

### 4.4 预约时间选择交互

```
[点击日期选择]
       ↓
[日历展开，显示当月]
       ↓
[选择日期]
       ↓
[加载该日期的可用时间段]
       ↓
[显示时间段列表（可用/已满状态）]
       ↓
[选择时间段]
       ↓
[更新订单中的预约信息]
```

### 4.5 支付流程

```
[在支付页面点击"微信支付"]
       ↓
[调用 payment.js 的发起支付方法]
       ↓
[调用云函数 order.pay 获取支付参数]
       ↓
[调用 wx.requestPayment 唤起微信支付]
       ↓
[支付完成/取消]
       ↓
[跳转到订单详情页，状态更新]
```

## 5. 关键交互细节

### 5.1 SKU 选择（规格联动）

**交互逻辑**:
1. 每个规格维度独立选择
2. 选择后联动计算唯一 SKU
3. SKU 不存在或库存为 0 时不可选
4. 价格实时联动更新

**状态定义**:
- `available`: 可选
- `disabled`: 不可选（库存不足）
- `selected`: 已选中

### 5.2 预约时间选择

**交互逻辑**:
1. 先选日期，再选时间段
2. 已约满的时间段不可选
3. 超过今日的时间段才可选（不选过去）

**状态定义**:
- `available`: 可预约
- `full`: 已约满
- `selected`: 已选择
- `past`: 不可选（已过期）

### 5.3 地址选择

**交互逻辑**:
1. 配送方式切换时重置地址选择
2. 配送时必须有默认地址或手动选择
3. 支持新增地址后直接选择

### 5.4 订单创建

**交互逻辑**:
1. 前置条件校验（地址、预约时间必填）
2. 提交前二次确认
3. 创建中禁止重复点击
4. 创建成功后跳转支付页

**错误处理**:
- 库存不足：提示用户返回修改
- 预约时段已满：提示重新选择
- 网络错误：提示重试

## 6. 需明确的架构决策

### 6.1 状态管理方案

**待决策**: 是否引入额外状态管理库？

**方案A（推荐）**: 仅使用页面 `data` 和 `setData`
- 理由：小程序内存有限，页面级状态足够
- 适用场景：状态简单的页面

**方案B**: 引入 `glass-easel` 的 store 模块
- 理由：跨页面共享状态（如购物车）
- 适用场景：复杂状态需要共享的场景

**建议**: MVP 阶段使用方案A，若后续购物车等模块需要再引入 store

### 6.2 接口请求封装

**待决策**: 是否统一处理登录态失效？

**建议**: 在 `services/api.js` 中统一封装：
- 请求前检查 token 有效性
- 401 时自动跳转登录页
- 网络错误统一提示

## 7. 非功能性需求

### 7.1 性能要求

- 首屏加载时间 < 2s（依赖云开发冷启动）
- 页面切换流畅（避免频繁 setData）
- 图片懒加载（列表页）

### 7.2 兼容性要求

- iOS 12+、Android 8+（微信版本要求）
- 不同屏幕尺寸适配（rpx）

### 7.3 安全要求

- 不在前端存储敏感信息
- 接口调用携带 token
- 支付金额以后端计算为准
