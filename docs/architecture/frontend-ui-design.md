# 前端UI设计文档

## 1. 概述

### 1.1 文档目的

本文档定义蛋糕工作室微信小程序的UI视觉规范、页面布局、交互动效及状态设计，为前端开发提供可执行的视觉参考。

### 1.2 品牌调性

**关键词**: 温馨、精致、手工、品质

**视觉语言**:
- 整体风格偏向温暖柔和，避免冷硬的几何感
- 强调留白和呼吸感，体现精致感
- 使用圆润的边角和柔和的阴影
- 色彩以暖色调为主，搭配精致的点缀色

### 2.6 图标规范

#### 图标风格

- 风格: 线性图标为主，2px 线宽
- 尺寸基准: 48rpx（标准）、40rpx（小型）、64rpx（大型）
- 颜色: 跟随文字颜色（text-primary/text-secondary/text-assist）
- 颜色值: #4A3728（重要）、#8B7355（次要）、#B8A089（辅助）

#### 关键图标尺寸

```
底部导航图标: 48rpx
功能入口图标: 64rpx 或 80rpx
列表项图标: 40rpx
商品规格图标: 32rpx
```

#### 图标命名规范

```
ic_[类型]_[名称]_[尺寸]
示例: ic_nav_home_48, ic_goods_cake_64, ic_arrow_right_24
```

## 3. 组件视觉规范

### 3.1 按钮

#### 主按钮

```
高度: 88rpx
圆角: 12rpx
背景: #F5DCC3
文字: #4A3728，字号 32rpx，字重 500
内边距: 0 48rpx
```

**状态定义:**

| 状态 | 视觉表现 |
|------|---------|
| 默认 | 背景 #F5DCC3 |
| Hover/Pressed | 背景 #E8C4A0，阴影按下态 |
| Disabled | 背景 #E8E0D8，文字 #B8A089 |
| Loading | 背景不变，显示 loading 动画 |

#### 次要按钮（描边）

```
高度: 88rpx
圆角: 12rpx
背景: #FFFFFF
边框: 2rpx solid #E8C4A0
文字: #4A3728，字号 32rpx，字重 500
```

**状态定义:**

| 状态 | 视觉表现 |
|------|---------|
| 默认 | 背景白，边框奶黄 |
| Hover/Pressed | 背景 #FBF3EB |
| Disabled | 边框 #E8E0D8，文字 #B8A089 |

#### 文字按钮

```
无背景，无边框
文字: #E8A0A0（莓红），字号 28rpx
下划线: 无（避免繁琐）
```

#### 按钮间距

```

```

## 6. 交互动效

### 6.1 页面切换动画

#### 页面进入

| 页面类型 | 动画 | 时长 | 缓动函数 |
|---------|------|------|---------|
| 主页面（Tab切换） | 无 | - | - |
| 详情页 | 从右侧滑入 | 300ms | ease-out |
| 支付页 | 从底部滑入 | 300ms | ease-out |
| 弹窗/浮层 | 淡入+缩放 | 250ms | ease-out |

#### 页面返回

| 页面类型 | 动画 | 时长 | 缓动函数 |
|---------|------|------|---------|
| 详情页 | 向右滑出 | 250ms | ease-in |
| 支付页 | 向底部滑出 | 250ms | ease-in |

### 6.2 组件动画

#### 按钮点击

```
动画: scale(0.96)
时长: 100ms
缓动: ease-out
恢复: 150ms
```

#### 卡片点击

```
动画: scale(0.98) + 阴影加深
时长: 150ms
缓动: ease-out
```

#### 收藏/点赞

```
动画: scale(1.2) → scale(1) + 颜色变化
时长: 300ms
缓动: ease-in-out
```

#### 数量增减

```
动画: 数字 scale(1.1) → scale(1)
时长: 200ms
```

#### SKU 选项展开

```
动画: max-height 过渡 + fade
时长: 250ms
缓动: ease-out
```

### 6.3 加载动画

#### 品牌加载动画

```
蛋糕图标旋转:
  时长: 1s / 周
  缓动: linear
  循环: 无限
```

#### 列表加载更多

```
三个点依次跳动:
  动画: translateY(-6rpx) → translateY(0)
  间隔: 100ms
  时长: 400ms
  缓动: ease-out
```

### 6.4 骨架屏动画

```
Shimmer 效果:
  从左到右渐变遮罩移动
  颜色: rgba(255,255,255,0.3) → rgba(255,255,255,0.6) → rgba(255,255,255,0.3)
  时长: 1.5s
  缓动: linear
  循环: 无限
```

### 6.5 弹窗动画

#### 底部弹窗

```
进入:
  背景: fade in, 0 → 0.5
  内容: translateY(100%) → translateY(0)
  时长: 300ms
  缓动: ease-out

退出:
  背景: fade out
  内容: translateY(0) → translateY(100%)
  时长: 250ms
  缓动: ease-in
```

#### 中间弹窗

```
进入:
  背景: fade in
  内容: scale(0.9) → scale(1) + opacity 0 → 1
  时长: 250ms
  缓动: ease-out

退出:
  内容: scale(1) → scale(0.9) + opacity 1 → 0
  时长: 200ms
  缓动: ease-in
```

### 6.6 页面内元素出现动画

#### 列表项渐入

```
动画: opacity 0 → 1 + translateY(20rpx) → translateY(0)
时长: 300ms
间隔: 每项 50ms（stagger）
缓动: ease-out
```

#### 分类切换

```
动画: opacity + translateX
新内容从右侧滑入: translateX(30rpx) → 0
旧内容向左滑出: translateX(0) → -30rpx
时长: 250ms
```

### 6.7 预约时间选择器

#### 日期切换

```
动画: 整体 opacity + translateX
上月: 新内容从右来 translateX(30rpx) → 0
下月: 新内容从左来 translateX(-30rpx) → 0
时长: 200ms
```

#### 时间段选中

```
动画: scale(1) → scale(0.95) → scale(1) + 边框颜色变化
时长: 200ms
```

### 6.8 下单成功动效

```
动画序列:
  1. 对勾图标 scale(0) → scale(1.2) → scale(1)  (400ms)
  2. 文字 fade in (200ms)
  3. 按钮 slide up (200ms)
```

### 8.4 关键流程状态变化

```
商品详情 → 加入订单:
  触发: 点击"加入订单"按钮
  前置校验: SKU已选、预约时间已选
  动画: 按钮loading → 成功提示 → 跳转订单确认页
  失败: toast提示"请选择规格"

订单确认 → 提交订单:
  触发: 点击"提交订单"按钮
  前置校验: 配送方式必填、配送地址必填（配送时）、预约时间必填
  动画: 按钮loading → 跳转支付页
  失败: modal提示错误原因

支付 → 支付成功:
  触发: 微信支付回调成功
  动画: 支付中loading → 成功页动画（对勾+文案）
  跳转: 2秒后自动跳转订单详情，或点击"查看订单"立即跳转

支付 → 支付失败:
  触发: 微信支付回调失败或取消
  状态: 显示失败原因，按钮变为"重新支付"
  操作: 可重试或取消订单
```

## 9. 适配说明

### 9.1 安全区域适配

```
iPhone X 及以上设备:
  底部导航栏增加 34rpx（或 dynamicHeight）安全区域
  固定底部操作栏增加对应安全区域
  导航栏状态栏高度根据 wx.getSystemInfoSync().statusBarHeight 动态计算
```

### 9.2 屏幕适配

```
使用 rpx 单位，实现以下适配:
  小屏（320px）: 元素缩小至 0.85x
  标准屏（375px）: 1x
  大屏（414px）: 1.1x
  极大屏（>414px）: 1.2x

商品卡片:
  宽度: (750rpx - 32rpx - 24rpx) / 2 = 347rpx
  图片高度: 320rpx
  整体高度: 360rpx（包含文字区域）
```

### 9.3 字体适配

```
字号不随系统字体大小变化
固定使用设计稿字号（rpx单位）
避免使用动态字号
```
