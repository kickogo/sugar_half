## 2. 云开发控制台配置

### 2.1 创建集合

**操作步骤**：

1. 打开微信开发者工具
2. 点击顶部**"云开发"**按钮，进入云开发控制台
3. 切换到**"数据库"**标签
4. 点击**"新建集合"**按钮
5. 输入集合名称，点击确认

**需要创建的集合**（按顺序创建）：

| 序号 | 集合名称 | 说明 |
|------|----------|------|
| 1 | `users` | 用户/商家账号 |
| 2 | `categories` | 商品分类 |
| 3 | `products` | 商品主数据 |
| 4 | `fills` | 夹馅选项 |
| 5 | `sku_items` | SKU 库存 |
| 6 | `orders` | 订单主表 |
| 7 | `order_items` | 订单明细 |

### 2.2 集合设置

创建集合后，建议进行以下设置：

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 备份 | 开启 | 防止数据丢失 |
| 索引数上限 | 10 | 够用即可 |
| 记录数上限 | 默认 | 按需调整 |

### 3.1 users - 用户/商家账号

**用途**：存储用户和商家的账户信息，用于登录认证。

#### 数据结构

```json
{
  "_id": "自动生成",
  "openid": "微信用户唯一标识",
  "phone": "手机号码",
  "nickname": "用户昵称",
  "avatar": "头像URL",
  "is_admin": false,
  "member_level": 1,
  "balance": 0,
  "points": 0,
  "status": 1,
  "created_at": "创建时间",
  "updated_at": "更新时间"
}
```

#### 字段说明

| 字段名 | 类型 | 必填 | 默认值 | 数据范围 | 说明 |
|--------|------|------|--------|----------|------|
| `_id` | String | 自动 | - | - | 云数据库自动生成 |
| `openid` | String | 用户必填 | - | 28-64字符 | 微信用户唯一标识 |
| `phone` | String | 商家必填 | - | 11位数字 | 手机号，regex: `^1[3-9]\d{9}$` |
| `nickname` | String | 否 | - | 1-20字符 | 用户昵称 |
| `avatar` | String | 否 | 空字符串 | 最大500字符 | 头像图片URL |
| `is_admin` | Boolean | 是 | `false` | true/false | 是否商家账号 |
| `member_level` | Number | 是 | `1` | 1-99 | 会员等级 |
| `balance` | Number | 是 | `0` | 0-99999999 | 账户余额（分） |
| `points` | Number | 是 | `0` | 0-99999999 | 积分数量 |
| `status` | Number | 是 | `1` | 0-1 | 0=禁用，1=正常 |
| `created_at` | Date | 自动 | 当前时间 | - | 创建时间戳 |
| `updated_at` | Date | 自动 | 当前时间 | - | 更新时间戳 |

#### 权限设置（推荐）

```
所有用户: 不可读写
仅创建者: 可读可写
管理员: 可读可写
```

#### 示例数据

```json
{
  "openid": "oABC123xxxxxxxxxxxxxx",
  "phone": "13800138000",
  "nickname": "张三",
  "avatar": "",
  "is_admin": false,
  "member_level": 1,
  "balance": 0,
  "points": 0,
  "status": 1
}
```

### 3.5 sku_items - SKU 库存

**用途**：存储完整的 SKU 规格组合，包含价格和库存。

#### 数据结构

```json
{
  "_id": "自动生成",
  "product_id": "商品ID",
  "sku_key": "size_6寸_fill_布丁_cream_动物",
  "sku_name": "6寸 | 布丁 | 动物奶油",
  "size": "6寸",
  "fills": ["布丁"],
  "cream": "动物",
  "specs": "{\"尺寸\":\"6寸\",\"夹馅\":\"布丁\",\"奶油\":\"动物奶油\"}",
  "price": 31800,
  "stock": 10,
  "status": 1,
  "created_at": "创建时间",
  "updated_at": "更新时间"
}
```

#### 字段说明

| 字段名 | 类型 | 必填 | 默认值 | 数据范围 | 说明 |
|--------|------|------|--------|----------|------|
| `_id` | String | 自动 | - | - | 云数据库自动生成 |
| `product_id` | String | 是 | - | 有效ID | 关联 products._id |
| `sku_key` | String | 是 | - | 最大100字符 | SKU唯一标识键 |
| `sku_name` | String | 是 | - | 最大100字符 | SKU显示名称 |
| `size` | String | 是 | - | 4寸/6寸/8寸/10寸 | 尺寸规格 |
| `fills` | Array | 是 | - | 夹馅名称数组 | 夹馅列表 |
| `cream` | String | 是 | - | 动物/植脂 | 奶油类型 |
| `specs` | String | 是 | - | JSON字符串 | 规格键值对 |
| `price` | Number | 是 | - | 1-99999999 | 最终价格（分） |
| `stock` | Number | 是 | `10` | 0-9999 | 库存数量 |
| `status` | Number | 是 | `1` | 0-1 | 0=下架，1=上架 |
| `created_at` | Date | 自动 | 当前时间 | - | 创建时间戳 |
| `updated_at` | Date | 自动 | 当前时间 | - | 更新时间戳 |

#### 尺寸规格（size）

| size | 中文 | sizePriceMod（分） | sizePriceMod（元） |
|------|------|-------------------|-------------------|
| 4寸 | 4英寸 | 0 | 0 |
| 6寸 | 6英寸 | 6000 | 60 |
| 8寸 | 8英寸 | 10000 | 100 |
| 10寸 | 10英寸 | 16000 | 160 |

#### 奶油类型（cream）

| cream | 中文 | creamPriceMod（分） | creamPriceMod（元） |
|-------|------|--------------------|--------------------|
| 动物 | 动物奶油 | 0 | 0 |
| 植脂 | 植脂奶油 | -2000 | -20 |

#### 价格计算公式

```
最终价格 = base_price + sizePriceMod[size] + creamPriceMod[cream] + Σfill.price_mod
```

**计算示例**：
- 草莓慕斯（base_price = 26800）
- 6寸（+6000）
- 布丁（+500）
- 动物奶油（+0）
- **最终价格 = 26800 + 6000 + 500 + 0 = 33300（333元）**

#### SKU 组合数量

每个商品的 SKU 数量计算：
- 尺寸：4 种（4寸、6寸、8寸、10寸）
- 奶油：2 种（动物、植脂）
- 夹馅组合：无、单夹馅、双夹馅

以草莓慕斯为例（7 种夹馅 + 无夹馅）：
- 无夹馅：4 × 2 = 8 个
- 单夹馅：8 × 7 = 56 个
- 双夹馅：C(8,2) × 4 × 2 = 112 个
- **小计：176 个 SKU**

两个商品合计约 352 个 SKU。

#### 权限设置（推荐）

```
所有用户: 仅可读
仅创建者: 可读可写
管理员: 可读可写
```

### 3.6 orders - 订单主表

**用途**：存储订单主信息，包括订单号、金额、状态、取货时间等。

#### 数据结构

```json
{
  "_id": "自动生成",
  "order_no": "ORD20260511143000123456",
  "user_id": "用户ID",
  "status": 0,
  "total_amount": 31800,
  "pay_amount": 31800,
  "delivery_type": 1,
  "reservation_date": "2026-05-15",
  "reservation_time": "14:00",
  "remark": "备注",
  "created_at": "创建时间",
  "updated_at": "更新时间"
}
```

#### 字段说明

| 字段名 | 类型 | 必填 | 默认值 | 数据范围 | 说明 |
|--------|------|------|--------|----------|------|
| `_id` | String | 自动 | - | - | 云数据库自动生成 |
| `order_no` | String | 是 | - | 22-30字符 | 订单号，格式：ORD+时间戳+随机数 |
| `user_id` | String | 是 | - | 有效ID | 下单用户关联 users._id |
| `status` | Number | 是 | `0` | 0-5 | 订单状态 |
| `total_amount` | Number | 是 | - | 1-99999999 | 商品总价（分） |
| `pay_amount` | Number | 是 | - | 0-99999999 | 实付金额（分） |
| `delivery_type` | Number | 是 | `1` | 1 | 配送类型，1=到店自提 |
| `reservation_date` | String | 是 | - | yyyy-MM-dd | 预约取货日期 |
| `reservation_time` | String | 是 | - | HH:mm | 预约取货时间 |
| `remark` | String | 否 | 空字符串 | 最大200字符 | 订单备注 |
| `created_at` | Date | 自动 | 当前时间 | - | 创建时间戳 |
| `updated_at` | Date | 自动 | 当前时间 | - | 更新时间戳 |

#### 订单状态（status）

| status | 状态名 | 说明 | 可转换操作 |
|--------|--------|------|-----------|
| 0 | 待付款 | 等待用户支付 | 支付成功 → 1 / 取消 → 5 |
| 1 | 已付款 | 已支付，等待商家确认 | 商家确认 → 2 / 超时取消 → 5 |
| 2 | 制作中 | 商家已确认，开始制作 | 制作完成 → 3 |
| 3 | 待自提 | 制作完成，等待用户取货 | 用户取货 → 4 |
| 4 | 已完成 | 交易完成 | 终止态 |
| 5 | 已取消 | 订单已取消 | 终止态 |

#### 订单号生成规则

```
前缀：ORD
时间戳：yyyyMMddHHmmss（14位）
随机数：6位随机数字（100000-999999）

示例：ORD20260511143000123456
      ORD + 20260511143000 + 123456
```

#### 权限设置（推荐）

```
所有用户: 不可读写
仅创建者: 可读可写（查询自己的订单）
管理员: 可读可写（管理所有订单）
```

## 4. 索引配置

索引可提升查询性能，建议为常用查询字段创建索引。

### 4.1 创建索引方法

1. 在云开发控制台 → 数据库 → 选择集合
2. 点击"索引"标签
3. 点击"添加索引"
4. 选择字段，设置升序/降序，勾选是否唯一
5. 点击确认

### 4.2 各集合索引

#### users

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `openid` | 升序 | 是 | 用于微信登录快速查询 |
| `phone` | 升序 | 否 | 用于商家手机号登录 |

#### categories

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `name` | 升序 | 是 | 确保分类名唯一 |
| `status` | 升序 | 否 | 按状态筛选 |
| `status, sort` | 升序 | 否 | 复合索引，按状态和排序查询 |

#### products

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `category_id, status` | 升序 | 否 | 按分类查询上架商品 |
| `created_at` | 降序 | 否 | 按时间倒序排列 |

#### fills

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `status, sort` | 升序 | 否 | 按状态和排序查询 |

#### sku_items

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `sku_key` | 升序 | 是 | 确保SKU标识唯一 |
| `product_id, status` | 升序 | 否 | 按商品查询SKU |
| `stock` | 升序 | 否 | 查询低库存SKU |

#### orders

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `order_no` | 升序 | 是 | 订单号唯一索引 |
| `user_id, status` | 升序 | 否 | 按用户查询订单 |
| `created_at` | 降序 | 否 | 按时间倒序排列 |

#### order_items

| 字段 | 顺序 | 唯一 | 说明 |
|------|------|------|------|
| `order_id` | 升序 | 否 | 按订单查询明细 |

## 5. 权限配置

微信云数据库的权限分为**记录级权限**和**字段级权限**。

### 5.1 权限类型

| 权限 | 说明 |
|------|------|
| 所有用户可读 | 所有用户都能读取数据 |
| 所有用户可读/写 | 所有用户都能读写数据 |
| 仅创建者可读/写 | 只有创建记录的用户可以读写 |
| 仅管理员可读/写 | 只有管理员可以读写 |
| 仅管理员可读 | 只有管理员可以读取 |

### 5.2 推荐权限配置

| 集合 | 读取权限 | 写入权限 | 说明 |
|------|---------|---------|------|
| `users` | 仅创建者可读 | 仅创建者可写 | 保护用户隐私 |
| `categories` | 所有用户可读 | 仅管理员可写 | 公开分类信息 |
| `products` | 所有用户可读 | 仅管理员可写 | 公开商品信息 |
| `fills` | 所有用户可读 | 仅管理员可写 | 公开夹馅信息 |
| `sku_items` | 所有用户可读 | 仅管理员可写 | 公开库存信息 |
| `orders` | 仅创建者可读 | 仅创建者可写 | 保护订单隐私 |
| `order_items` | 仅创建者可读 | 仅创建者可写 | 保护订单明细隐私 |

### 5.3 安全注意事项

- **用户敏感信息**（phone、balance、points）不要设置"所有用户可读"
- **订单数据**必须限制为"仅创建者可读"，防止用户查看他人订单
- **管理员权限**通过云函数逻辑控制，不依赖数据库权限

## 8. 常见问题

### Q: 报错 "collection not exist"

**原因**：集合尚未创建。

**解决**：在云开发控制台 → 数据库 → 新建集合。

### Q: 报错 "permission denied"

**原因**：数据库权限不足。

**解决**：
1. 检查集合权限设置
2. 通过云函数访问（云函数有管理员权限）

### Q: 初始化数据重复

**原因**：`initData` 云函数检查到已有数据时会跳过。

**解决**：这是正常行为，确保数据不会重复初始化。

### Q: 如何重置数据

**解决**：
1. 在云开发控制台手动删除集合记录
2. 重新调用 `initData` 云函数
